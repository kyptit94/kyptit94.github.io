---

## 🤔 What is Dependency Injection?

Dependency Injection is a technique where **an object receives other objects it depends on**, rather than creating them internally.

### Without Dependency Injection:

```php
class UserController {
    protected $userService;

    public function __construct() {
        $this->userService = new UserService(); // tightly coupled
    }
}
```

The `UserController` is now **tightly coupled** to `UserService`, making it harder to test or swap out.

---

## ✅ With Dependency Injection:

```php
class UserController {
    protected $userService;

    public function __construct(UserService $userService) {
        $this->userService = $userService;
    }
}
```

The dependency (`UserService`) is **injected from outside**, making the controller more flexible and testable.

# 🧱 3 Main Dependency Injection Patterns in PHP

## 1. Constructor Injection (Most Common)

Dependencies are passed through the constructor.

```php
class Mailer {
    protected $logger;

    public function __construct(LoggerInterface $logger) {
        $this->logger = $logger;
    }
}
```

### ✅ Pros:
- Immutable (you must provide the dependency)
- Great for required dependencies
- Easy to test

---

## 2. Setter Injection

Dependencies are set via setter methods after object construction.

```php
class Mailer {
    protected $logger;

    public function setLogger(LoggerInterface $logger) {
        $this->logger = $logger;
    }
}
```

### ✅ Pros:
- Good for optional dependencies

### ⚠️ Cons:
- Object may be incomplete until the setter is called

---

## 3. Interface Injection (Less common in PHP)

The dependency provides an interface that the dependent class must implement.

```php
interface LoggerAwareInterface {
    public function setLogger(LoggerInterface $logger);
}

class Mailer implements LoggerAwareInterface {
    protected $logger;

    public function setLogger(LoggerInterface $logger) {
        $this->logger = $logger;
    }
}
```

Used when you want to enforce injection at a broader level (e.g., through frameworks).

# 🧪 Dependency Injection in Frameworks

Modern PHP frameworks like Laravel, Symfony, and Laminas use DI extensively through **service containers**.

Example in Laravel:

```php
class InvoiceController {
    public function __construct(InvoiceService $invoiceService) {
        $this->invoiceService = $invoiceService;
    }
}
```

Laravel’s service container resolves `InvoiceService` automatically!

# 🛠 Tips for Clean DI in PHP

- Favor constructor injection for clarity
- Avoid creating new objects inside classes (use DI instead)
- Use interfaces for flexibility
- Use a service container for large applications

---

## 🧩 Bonus: Combine DI with Design Patterns

Dependency injection pairs well with:

- Decorator Pattern
- Repository Pattern
