## 🧠 What Are Lifecycle Hooks?

Lifecycle hooks are **functions** that get called at **specific stages** of a component’s lifecycle—from creation to destruction.

This includes phases like:

- Before/after mounting
- Before/after updating
- Before unmounting

Each phase gives you a chance to **hook into the lifecycle** and perform side effects (e.g., fetching data, cleanup, subscriptions, etc.).

---

## 🔄 Vue 3 Lifecycle Flow (Simplified)

1. `setup()` (Composition API only)
2. `beforeCreate` *(Options API)*
3. `created`
4. `beforeMount`
5. `mounted`
6. `beforeUpdate`
7. `updated`
8. `beforeUnmount`
9. `unmounted`

---

## ⚙️ Lifecycle Hooks in the Composition API

In Vue 3's Composition API, you use lifecycle hooks from the `vue` package directly in the `setup()` function:

```ts
import { onMounted, onUnmounted, onUpdated } from 'vue';

export default {
  setup() {
    onMounted(() => {
      console.log('Component mounted');
    });

    onUnmounted(() => {
      console.log('Component destroyed');
    });

    onUpdated(() => {
      console.log('Component updated');
    });
  }
};
```

## 📘 Lifecycle Hooks in the Options API

If you're using the classic `data`, `methods`, `mounted` format:

```js
export default {
  data() {
    return {
      count: 0
    };
  },
  mounted() {
    console.log('Component mounted');
  },
  updated() {
    console.log('Component updated');
  },
  beforeUnmount() {
    console.log('Cleaning up...');
  }
};
```

Vue 3 supports both APIs — use the one that fits your style or project.

---

## 🧪 Common Lifecycle Hooks and Use Cases

| Hook            | When It Runs                         | Common Use Case                        |
|------------------|---------------------------------------|-----------------------------------------|
| `onMounted`      | After the component is mounted        | API calls, event listeners              |
| `onBeforeMount`  | Just before mounting begins           | Logging, initial state setup            |
| `onUpdated`      | After reactive data causes re-render  | DOM manipulation, side effects cleanup  |
| `onBeforeUnmount`| Just before the component is removed  | Remove event listeners, clear timers    |
| `onUnmounted`    | After the component is destroyed      | Final cleanup, disconnect sockets       |

---

## 🧩 Example: API Call on Mount

```ts
import { ref, onMounted } from 'vue';

export default {
  setup() {
    const users = ref([]);

    onMounted(async () => {
      const res = await fetch('/api/users');
      users.value = await res.json();
    });

    return { users };
  }
}
```

## 🔄 Using Watchers with Lifecycle

You can also combine lifecycle with `watch` for reactive control:

```ts
import { ref, watch } from 'vue';

const count = ref(0);

watch(count, (newVal, oldVal) => {
  console.log(`Count changed from ${oldVal} to ${newVal}`);
});
```

This runs whenever `count` changes — works great with `onMounted` or `onUpdated`.

## 🧠 Interview Tips

**"What's the difference between `mounted` and `onMounted`?"**

> "`mounted` is used in Options API. `onMounted` is used in Composition API within `setup()`."

**"When should you clean up listeners?"**

> "Inside `onBeforeUnmount` or `onUnmounted` to avoid memory leaks."

**"What can you do in `onMounted`?"**

> "Trigger API calls, subscribe to services, or manipulate the DOM."
